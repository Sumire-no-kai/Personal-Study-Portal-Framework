## A2 复现与阻断范围

1. 在此前保存了 1.2 同意记录、已完成指引及一个仍存在的临时资料库的主机上，运行上述 x64 安装包覆盖安装。
2. 首次启动显示 1.3 提示。打开全文并滚到末尾，切换界面语言，勾选并点击“同意并继续”。
3. **实际：**仍在同意页，报“无法安全替换本机设置文件。”。**预期：**回到已保存资料库的状态页，自动启动服务并显示原有笔记数，不自动打开浏览器。

为区分界面门槛与设置写入问题，先按 SHA-256 备份旧设置，再用临时测试设置启动同一安装版。状态页仍显示上述错误、服务保持“已停止”、笔记数为 0；手动点击“启动服务”也出现同样错误且没有监听端口。这一绕过**不计入 A2 通过**。

本机应用设置目录和原设置文件均带 Windows `Encrypted` 属性。独立的同目录 `MoveFileExW` 探针在不允许复制回退时返回 Windows 错误 17；允许复制回退时可成功，普通未加密临时目录也可重命名。安装版自身只显示中文错误文本，没有输出底层错误码，因此探针是定位线索，**不能证明安装版内部正好收到错误 17，也不能单独证明加密属性就是根因**。工具会话对该目录执行 `cipher /D` 被 Windows 拒绝访问；本机用户手动执行同一路径的命令返回“找不到文件”。复查目录和文件仍保持加密，原设置 SHA-256 与测试前备份一致。没有关闭安全防护或更改系统加密状态。

测试结束时应用已退出；原设置已恢复并核对哈希，设置目录仍保持加密，本轮生成的额外设置副本已清除。临时资料库的 13 个基线文件全部存在且大小与 SHA-256 未变，没有额外文件；仓库公开示例原件未修改，也未接触真实笔记。本轮只证明上述安装包在这台主机上的结果；未完成的项目仍需在设置写入正常的 Windows x64 环境重测。
