# Note Portal 完整使用提示

**版本：1.3**

Note Portal 是独立开发的本机 Markdown 阅读工具，帮助你整理、阅读和检索自己有权使用的笔记、文档与日志。学习笔记是重要用途，但本工具不代表任何学校，也不会替你判断一份资料是否可以使用或分享。

## 学术诚信、版权与使用责任

使用前，请检查并遵守你所在学校、院系、课程及考试的学术诚信规定，以及适用的版权、隐私、保密和信息安全要求。不同场景的规定可能不同；本提示不能替代学校规则或专业法律意见。

本工具不会授予你复制、处理、发布或分享课程材料、评估内容、个人信息或第三方作品的权利。请勿用它侵犯版权、泄露受限资料、规避学术诚信要求、未经授权访问，或从事其他违法或违反适用规定的行为。你需要对导入、处理、展示和分享的内容及使用方式负责。如不确定，请先保持资料私有，并向学校、资料权利人或合适的专业人士确认。

## 本机处理与隐私

应用只读取你明确选择的资料库文件夹，在本机生成导航、哈希与搜索数据。当前版本没有云账户或内置 AI 服务，也不会主动上传笔记内容。已有 Markdown 和图片保持在原位置；扫描、阅读、搜索和刷新不会自动移动、改名、覆盖或删除它们。只有你明确点击“创建笔记”或“创建 Week 模板”时，应用才会新建文件，而且不会覆盖同名文件。你使用的编辑器、自动化工具或外部 AI 服务如何处理资料，由那些工具及其设置决定。

本地设置仅保存所选资料库、外观与启动选项，以及本提示的同意版本和时间。诊断可能显示资料库内的相对路径，但不应包含完整笔记正文或凭据。请留意，电脑上其他有权限的用户或程序仍可能访问你的本地文件。

## 网络访问与分享

阅读服务默认只监听你这台电脑的回环地址。建议只在自己的电脑上使用；当前版本不支持直接部署到公网。公网或远程分享可能意外暴露课程资料、评估内容、私人笔记和个人信息。如确需分享，请先确认授权，并使用适当的身份验证、访问控制与安全传输；不要把这个本地阅读服务直接暴露给互联网。

## 非学校官方产品

Note Portal 是独立工具。显示学校名称、课程代码或你自行选择的 Logo，不表示相关机构认可、批准、验证或支持本工具。

应用源代码和随附第三方组件受各自的开源许可证约束。下方附有本项目许可证文本；随阅读器提供的 Marked 和 KaTeX 保留各自的 MIT 许可证。开源许可不授予使用、复制或分享你导入的第三方资料的权利。
