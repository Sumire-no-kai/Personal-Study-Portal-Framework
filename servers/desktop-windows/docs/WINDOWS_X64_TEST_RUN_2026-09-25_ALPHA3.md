## 资料库与 Markdown 完整性核对

- 复制仓库的 General/Study 虚构示例，另复制 6 份本学期复习 Markdown 到临时 General 库、其中 2 份到临时 Study 层级，并准备空库。对初始 20 个 Markdown/图片文件记录相对路径、大小和 SHA-256。应用未选择课程原件或仓库原始示例。
- 最大一篇笔记为 382,117 字节、6,620 行。alpha.3 Chrome 阅读器生成约 210,714 字符的可访问文本；开头、末尾和 10 个纵向分段抽样均在页面找到。检查代码围栏外、长度至少 8 字符的 282 个标题：264 个与原文直接匹配；另 18 个带 Markdown 加粗、行内代码或 LaTeX，去掉格式标记或比较公式之外的文字后也全部匹配。未观察到长文截断或标题遗漏；**这不是逐行无损证明**。
- Study 模式下，一篇 50,439 字节、815 行的本学期笔记显示约 27,657 字符；开头、中段和末尾清单都可找到。公开示例的相对 SVG 图片在 Chrome 中目视显示；中文文件名的临时 Inbox 笔记进入目录，搜索返回 1 条且可从结果打开。
- 测试结束并退出后，20 个基线文件中 18 个 SHA-256 未变、0 个缺失；2 个由测试者主动追加刷新标记，另有 6 个明确创建的临时测试文件。6 份课程原件与测试前哈希全部一致。没有观察到扫描、阅读、搜索或诊断改写其它文件。

## 问题与细节

### F-01 升级后完成必经引导，保存的库仍停在 Stopped

**版本/环境：**alpha.3 x64 包、Windows 25H2 构建 26200.9457；旧 alpha.2 测试设置保存了一个仍存在的空 General 库。安装新包后，新提示 1.2 要求重新同意。按要求读完提示并完成 3 页引导，点击“Finish guide and choose library”。实际进入控制页，旧库已选中，但状态是 Stopped、0 篇、未刷新，监听服务为 0，“Open reader”禁用；需手动点“Start service”或重选库。按钮文字和恢复已保存库的预期均提示应继续进入可用状态。此项**仅在旧设置升级路径复现**，不代表干净首次安装也失败。标签之后的 master 已有恢复保存库的代码提交；本报告没有把这些源码提交算作 alpha.3 安装包修复。

### F-02 长笔记刷新后阅读位置回到顶部（W-09）

**版本/环境：**同上；Chrome 阅读一份 382,117 字节、6,620 行的临时副本。用浏览器滚动模式定位至 40.00%，在外部追加新的二级标题并保存。随后页面和搜索均更新，但滚动值变成约 0.07%，仍是同一文档。第二次追加唯一标记后再次复现；6.33 秒的观察窗口尚未看到新标记，后续复查已看到，因此该窗口不能当作精确刷新延迟。**预期：**当前阅读位置尽量保持。**实际：**读者需要重新寻找原位置。未在其它浏览器或机器复测。

### F-03 托盘图标可用，但辅助功能名称为空

隐藏图标区出现绿色 Note Portal 图标，关闭控制窗口后点击可恢复，功能正常；Windows UI Automation 为该图标返回空 Name。可能影响依赖图标名称定位的辅助技术，尚未用实际屏幕阅读器验证。上轮没有找到托盘入口的结论已由本轮可见图标和恢复操作更新。

### F-04 选中 Logo 后文件输入仍写“No file chosen”

在设置中选择 158 字节的本机 PNG 后，状态说明变成“A logo is selected”、出现“Remove logo”，刷新 Chrome 后页眉实际显示该图片，但文件输入按钮的辅助功能名称仍含“No file chosen”。移除 Logo 后状态恢复。本轮未上传图片；这是状态文案不一致，不影响 Logo 显示。

## 性能与未覆盖范围

20 秒空闲样本：应用 CPU 时间增加 0.016 秒，按 20 个逻辑处理器折算约 0.004% 全核平均；末次工作集 75.7 MiB、私有内存 22.2 MiB、30 线程。Chrome 进程不计入此样本。它不能替代计划第 7 节的 5 分钟空闲、启动耗时或 100 MiB 大库预算验证。本机没有 Rust 工具链，未运行本地 Rust 测试或重新打包；本轮安装和运行的始终是公开 Release 包。本轮也未做重登自启、端口占用、恶意输入、100%/150% 缩放、全机断网、最终卸载或干净机器安装。应用已正常 Quit，安装留在测试机供后续检查；临时资料库保留在本机，未提交。
