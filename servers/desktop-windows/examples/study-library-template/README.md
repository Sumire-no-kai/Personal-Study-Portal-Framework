# Example Note Portal Study Library

This content-free fixture demonstrates the Study profile defined in
[`docs/LIBRARY_STRUCTURE.md`](../../docs/LIBRARY_STRUCTURE.md). Select this
directory as the library root and choose **Study notes**.

Only `content/` and `inbox/` participate in Study navigation. The recognised
weekly primary note is:

```text
content/2026-semester-2/DEMO101/week-01/week-01-notes.md
```
